* Example Projects
Minimal apps for manually testing JAL agent detection with ~lsp-java~ /
~eglot-java~.

** Single-module projects (~maven/~, ~gradle/~)
Minimal single-module bookstore apps. Both declare the three agents in
~jal-known-agents~:

| Agent                    | Role in this example                  |
|--------------------------+---------------------------------------|
| Lombok                   | ~@Value~ / ~@Builder~ on ~Book~       |
| JaCoCo                   | coverage on ~CartTest~                |
| OpenTelemetry Java Agent | runtime dependency for JAL resolution |

*** Maven
**** Run tests
#+begin_src shell
cd dev/test-projects/maven
./mvnw test # Or "./mvnw.bat test" on Windows
cd -        # Return to repo root

** Multi-module projects (~maven-multimodule/~, ~gradle-multimodule/~)
Minimal multi-module examples for manually testing JAL agent detection.

Module graph:

#+begin_example
subscription-commons   (leaf - no internal deps)
subscription-manager   -> subscription-commons   [+ Lombok, OTel, JaCoCo]
subscription-server    -> subscription-manager   [+ Lombok, OTel, JaCoCo]
#+end_example

*** Maven multi-module (~maven-multimodule/~)
Standalone Maven goals (e.g., ~dependency:list~) fail on uncompiled multi-module
projects when sibling submodules are absent from ~$HOME/.m2/repository~.
Prepending the compile lifecycle phase forces Maven to build the in-memory
reactor artifact map, enabling sibling dependency resolution and
agent/annotation processor detection without requiring a prior local repository
install.

**** Reproduce dependency resolution failure
#+begin_src shell
# Clear local repository cache for sibling submodules
rm -rf ~/.m2/repository/com/example

cd dev/test-projects/maven-multimodule

# Fails: Standalone goal lacks the reactor map needed to resolve uncompiled siblings
mvn -B dependency:list -DincludeArtifactIds=lombok
# -> BUILD FAILURE: Could not resolve com.example:subscription-commons:0.0.1
#+end_src

**** Verify fix with lifecycle execution
#+begin_src shell
# Succeeds: 'compile' populates the reactor artifact map before goal execution
mvn -B compile dependency:list -DincludeArtifactIds=lombok
# -> BUILD SUCCESS; lombok listed for subscription-manager and subscription-server
#+end_src

**** Run tests
#+begin_src shell
cd dev/test-projects/maven-multimodule
mvn -B test
cd -
#+end_src

**** Start test environment
#+begin_src shell
./dev/env/start-dev-env.sh eglot dev/test-projects/maven-multimodule
#+end_src
